# ADR-0001: REST через grpc-gateway

## Контекст

Сервису нужны и gRPC, и REST API. Писать их отдельно — дублировать логику.

## Решение

Использовать `grpc-gateway`. REST-роуты описываются аннотациями
`google.api.http` прямо в `.proto`, а gateway автоматически генерирует
HTTP-обёртку над gRPC.

## Последствия

- **+** Один контракт, один слой бизнес-логики.
- **+** REST получается бесплатно и всегда синхронен с gRPC.
- **−** Дополнительная зависимость `grpc-gateway`.
- **−** Нужны `third_party/google/api/*.proto`.
