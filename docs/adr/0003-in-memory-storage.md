# ADR-0003: In-memory хранилище с интерфейсами

## Контекст

Нужно хранить вёдра и правила. В production может потребоваться
распределённое хранилище (Redis), но для MVP — память.

## Решение

Определить интерфейсы `Limiter` и `IPRuleStore` в usecase-слое,
реализовать in-memory версии. При необходимости легко добавить Redis.

## Последствия

- **+** Usecase не знает о хранилище.
- **+** Простой деплой, минимум зависимостей.
- **−** При горизонтальном масштабировании состояние не разделяется;
  потребуется Redis-реализация.
